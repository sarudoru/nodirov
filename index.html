Colophon

This page has no scrollbar and never scrolls. The viewport is a fixed grid of character cells; a longer document passes through it the way tape passes a read head. Set in IBM Plex Mono, drawn on one canvas, written as one plain HTML document underneath — select, search, and view source as usual.

No frameworks, no tracking, no images. Only glyphs.
